Asas Pengaturcaraan

Memahami Konsep Asas Algoritma

Sebelum pelajar mula menulis kod C++, mereka perlu memahami bahawa program ialah satu set arahan yang disusun mengikut urutan tertentu untuk menyelesaikan sesuatu masalah. Algoritma bertindak sebagai pelan rancangan bertulis (resepi) manakala program komputer adalah pelaksanaan rancangan menggunakan bahasa pengaturcaraan (C++).

Plan
Algoritma = Perancangan berstruktur
Code
Program = Pelaksanaan menggunakan C++

Tiga Struktur Asas (Constructs)

Hampir kesemua perisian kompleks di dunia dibina menggunakan kombinasi gabungan tiga struktur ini sahaja.

Struktur 1 Turutan Satu-Hala

Sequential (Sequence)

Arahan dilaksanakan selangkah demi selangkah secara linear dari atas ke bawah tanpa sebarang loncatan, syarat, atau pengulangan. Setiap arahan hanya berjalan sekali sahaja.

// Contoh Pengiraan Jumlah
Harga = 15;
Kuantiti = 3;
Jumlah = Harga * Kuantiti;
cout << Jumlah;
Contoh Realiti:

Membuat secawan kopi bancuh, memasak mee segera instant.

Struktur 2 Membuat Pilihan

Conditional (Selection)

Program membuat semakan syarat logik sebelum memilih jalan mana yang harus diambil. Jika syarat dipenuhi (Ya), satu set tindakan diambil; jika gagal (Tidak), tindakan berbeza dilaksanakan.

// Contoh Semakan Keputusan
if (markah >= 50) {
  cout << "Lulus";
} else {
  cout << "Gagal";
}
Contoh Realiti:

Membawa payung (jika hari hujan), mengesahkan PIN kad ATM pelanggan.

Struktur 3 Pengulangan Pintar

Iterational (Looping)

Melakukan pengulangan satu atau beberapa baris tindakan secara berulang kali selagi sesuatu syarat dipenuhi. Amat efisien untuk melakukan tugas berskala besar dengan pantas.

// Papar nombor 1 hingga 5
for (int i = 1; i <= 5; i++) {
  cout << i << " ";
}
Contoh Realiti:

Memanggil senarai nama pelajar dalam kelas, mencuba PIN keselamatan telefon sebanyak 3 kali.
