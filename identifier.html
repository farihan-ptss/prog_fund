Modul : Identifier, Variable, Constant & Keywords

Asas melabel data, peraturan wajib pengaturcara, dan pengenalan kata kunci C++.

1. Apa itu Identifier?

Identifier ialah nama yang anda berikan kepada objek di dalam kod C++ seperti nama pemboleh ubah (variable), fungsi, atau objek bagi membolehkan komputer mengenal pasti kedudukan data tersebut dalam memori.

C++ Code
int age; // 'age' ialah Identifier
float salary; // 'salary' ialah Identifier
string name; // 'name' ialah Identifier

Peraturan Menamakan Identifier

Boleh Diikuti (✅)
  • ✨ Mengandungi huruf, nombor dan garis bawah (underscore _).
  • 👉 studentName
  • 👉 student_name
  • 👉 mark1
Dilarang Sama Sekali (❌)
  • 🚫 Mula dengan nombor (1student).
  • 🚫 Ada ruang kosong (student name).
  • 🚫 Guna Keyword C++ (int, float).

Penguji Identifier C++ Masa Nyata

2. Variable vs Constant

Mari kita bezakan antara bekas simpanan fleksibel (Variable) dengan bekas nilai yang dikunci mati (Constant).

Variable (Pemboleh Ubah)

Bekas menyimpan data yang nilainya **boleh berubah** semasa program berjalan.

int age = 18;
age = 19; // Nilai ditukar secara sah!

Constant (Pemalar)

Nilainya **kekal tetap** dan tidak boleh diubah sekali ia ditetapkan. Menggunakan keyword const.

const float PI = 3.142;
PI = 3.14; // ERROR! Nilai dikunci.

3. Initialize Variables

Initialize bermaksud meletakkan **nilai awal** di dalam variabel semasa ia diisytiharkan. Mengelakkan pemboleh ubah daripada memegang 'data sampah' rawak dalam memori.

Tanpa Initialize int age;
Sedia Initialize int age = 18;

4. Keywords terpelihara C++

Bahasa C++ mempunyai **kata kunci khas** yang dikhaskan untuk fungsi asas pengaturcaraan. Anda dilarang menggunakannya sebagai nama pemboleh ubah.

Modul iii: Data Types dalam C++

Memilih saiz memori dan jenis data yang sesuai dengan jenis maklumat.

Apa itu Data Type?

Jenis data memberitahu sistem komputer cara menterjemah bait memori komputer yang disimpan dan jumlah ruang bait (Bytes) yang diperuntukkan untuk sesuatu pemboleh ubah.

Analogi Almari: Ada bahagian kasut 👟, rak baju 👕, dan rak buku 📚. Setiap benda diletakkan di dalam bahagian tersendiri mengikut kategori saiz.
🗄️
Kategori Memori

Kategori Data Utama C++

int 4 Bytes

Integer (Nombor Bulat)

Nombor tanpa sebarang titik perpuluhan.

int age = 18;
float 4 Bytes

Floating Point (Perpuluhan)

Untuk nombor pecahan perpuluhan tinggi.

float weight = 55.5;
char 1 Byte

Character (Satu Aksara)

Satu huruf diapit tanda petikan tunggal '.

char grade = 'A';
bool 1 Byte

Boolean (Logik Benar/Salah)

Hanya mempunyai dua kemungkinan: true / false.

bool pass = true;
string Dinamik

String (Rangkaian Aksara / Teks)

Menyimpan perkataan atau satu ayat panjang diapit oleh tanda petikan berganda ".

string course = "Diploma IT";

Jadual Julat & Saiz Memori

Data Type Saiz (Byte) Anggaran Julat Contoh Kod
int 4 -2,147,483,648 hingga 2,147,483,647 100
float 4 ±3.4 × 10³⁸ (6-7 digit ketepatan) 3.14
char 1 -128 hingga 127 (ASCII) 'A'
bool 1 true (1) atau false (0) true
string Dinamik Tiada had tetap "Hello"
