Pengenalan & Anatomi Tatasusunan (Array)

Ketahui sebab utama tatasusunan digunakan dalam C++, definisi jenis data homogen, serta visualisasi langsung bagaimana Saiz (Size), Indeks (Index), dan Elemen (Element) berinteraksi di dalam memori komputer.

4.1 Mengapa Perlu Tatasusunan dalam C++?

Jika kita perlu menyimpan data umur bagi sekumpulan pelajar, tanpa tatasusunan kita terpaksa mencipta banyak pembolehubah individu: int umur1, umur2, umur3, umur4;.

Kelebihan Menggunakan Tatasusunan C++:
  • Semua data disimpan di bawah satu nama tatasusunan sahaja (contoh: umurPelajar).
  • Disimpan dalam alamat memori komputer yang bersebelahan (contiguous memory allocation).
  • Masa capaian sangat pantas O(1) menggunakan indeks aritmetik penunjuk (pointer arithmetic) dalam C++.

4.1.1 Definisi Tatasusunan (Array Definition)

Tatasusunan ialah koleksi elemen-elemen yang mempunyai jenis data yang sama (homogen), disimpan secara bersiri dalam blok memori berterusan dengan saiz yang telah ditetapkan semasa perisytiharan.

Contoh Deklarasi C++:

int umurPelajar[4]; // Saiz tetap 4 integer

Setiap integer memperuntukkan 4 bait memori fizikal yang berturutan.

Simulasi Konsep: Saiz (Size) → Indeks (Index) → Elemen (Element)

Tatasusunan Satu Dimensi (1D Array)

Perisytiharan (declaration), inisialisasi (initialization), serta capaian dan pengemaskinian elemen individu dalam C++.

4.1.4

Perisytiharan Tatasusunan 1D (Declare)

Dalam C++, perisytiharan menentukan jenis data, nama tatasusunan, dan saiz elemen di dalam kurungan siku [ ].

// Sintaks C++:

int markah[6];

Memperuntukkan 6 slot integer di dalam memori tanpa nilai awal (nilai rawak/garbage value sebelum diisi).

4.1.5

Inisialisasi Tatasusunan 1D (Initialize)

Meletakkan nilai permulaan ke dalam elemen menggunakan kurungan beralun { } semasa perisytiharan dilakukan.

// Inisialisasi Senarai Nilai C++:

int markah[6] = {55, 82, 74, 91, 63, 88};

Nilai disusun automatik mengikut indeks: markah[0]=55, markah[1]=82 ...

Tatasusunan Dua Dimensi (2D Array)

Matriks bergrid berstruktur Baris (Row) dan Lajur (Column) menggunakan dua pasang kurungan siku jadual[baris][lajur] dalam C++.

4.1.7

Perisytiharan Tatasusunan 2D (Declare)

Dalam C++, tatasusunan 2D diisytiharkan dengan menyatakan bilangan baris dan lajur dalam dua kurungan siku berasingan:

// Sintaks C++ (3 Baris, 4 Lajur):

int jadual[3][4];

4.1.8

Inisialisasi Tatasusunan 2D (Initialize)

Diisytiharkan bersama senarai kurungan beralun bersarang bagi mewakili setiap baris data:

// Inisialisasi Matriks 3 x 4:

int jadual[3][4] = {
  {12, 45, 67, 89},
  {34, 90, 42, 11},
  {78, 23, 56, 95}
};
