Apakah itu Pseudocode?

Pseudocode ialah cara menulis algoritma menggunakan bahasa yang menyerupai bahasa pengaturcaraan tetapi bebas daripada kekangan sintaks yang ketat (seperti C++). Ia ditulis dalam bahasa yang mudah difahami manusia untuk merancang logik program.

Tiga Tiang Penyelesaian Masalah

Mari bandingkan tiga bentuk cara merancang atur cara komputer:

Algorithm (Algoritma)

Langkah-langkah penyelesaian masalah dalam bentuk ayat biasa yang tersusun.

"Mula. Ambil berat dan tinggi. Bahagikan berat dengan tinggi berganda. Papar BMI. Tamat."

Flowchart (Carta Alir)

Langkah-langkah penyelesaian masalah dalam bentuk gambar rajah / simbol grafik standard.

[Terminal Oval] ➔ [Parallelogram Input] ➔ [Rectangle Process] ➔ [Terminal Oval]

Pseudocode (Pseudokod)

Langkah-langkah dalam bentuk hampir menyerupai kod program komputer tetapi mudah dibaca.

START
INPUT Weight, Height
BMI ← Weight / (Height * Height)
OUTPUT BMI
END

Mengapa Kita Menggunakan Pseudocode?

Sebelum menulis program dalam bahasa C++, seorang pengaturcara (programmer) biasanya menyediakan draf logik program terlebih dahulu. Ini mendatangkan banyak kelebihan:

  • ✔ Merancang Logik: Membantu anda berfikir secara sistematik tanpa memikirkan kesilapan sintaks / kompiler.
  • ✔ Pantas Diubah: Sangat mudah dibetulkan sekiranya berlaku kesilapan aliran pemikiran logik.
  • ✔ Komunikasi Mudah: Boleh difahami dengan senang oleh pengaturcara lain walaupun mereka tidak mahir C++.
  • ✔ Cetak Biru (Blueprint): Berfungsi sebagai panduan rujukan yang jitu ketika fasa menulis kod C++ sebenar.
