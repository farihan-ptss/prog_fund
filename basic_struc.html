🔍 Mengenali Struktur Asas C++ Satu Persatu

💬

a. Comments (Komen)

Nota kecil untuk programmer. Komputer akan mengabaikannya semasa program dijalankan.

// Komen satu baris
/* Komen yang panjang
& boleh ditulis banyak baris */

⭐️ Analogi: Seperti nota kecil guru di buku latihan. Guru baca, komputer tak peduli!

⚙️

b. Pre-processor

Arahan diproses SEBELUM program dikompil. Bermula dengan tanda #.

#include <iostream>

⭐️ Analogi: Sebelum memasak, anda kena ambil bahan dulu (Ambil telur, minyak, garam) sebelum dapur dibuka!

🧰

c. Header Files

Mengandungi fungsi sedia ada seperti cout (untuk tunjuk skrin) atau cin (input).

<iostream> // paparan
<cmath> // fungsi matematik

⭐️ Analogi: Kotak Alatan (Toolbox). Jika mahu guna spanar, pastikan kotak alatan itu dibawa dahulu!

🎬

d. Fungsi main()

Tempat mula program. Setiap program C++ MESTI ada fungsi utama ini.

int main() {
    // kod mula di sini
}

⭐️ Analogi: Babak pertama drama atau filem. Cerita sentiasa bermula di babak pertama!

🏁

e. Return Statement

Digunakan untuk menamatkan perjalanan program dengan tanda kejayaan.

return 0;

⭐️ Analogi: Butang "EXIT" selepas anda siap bermain permainan video kegemaran anda.

📜

Rumusan Ringkas

  • Comment: Nota sahaja
  • #include: Ambil fail luar
  • iostream: Alat baca & tulis
  • main(): Pintu utama mula
  • return 0: Selesai & Keluar

🏧 Analogi Mesin ATM

C++ menggunakan sistem Input dan Output yang dipermudahkan melalui analogi ATM ini:

PROSES ATM:
🔑 INPUT (cin >>) : Pengguna memasukkan kad dan menekan PIN atau nilai wang.
💰 OUTPUT (cout <<) : Skrin ATM menunjukkan baki duit anda atau mengeluarkan wang kertas!

💡 Tips Mudah Ingat Arah Simbol:

cin >>

Data "Masuk" ke dalam variable!

cout <<

Data "Keluar" dipapar ke skrin!

2 using namespace std;

7     cin >> name;
8     cout << "Masukkan Umur Anda: ";
9     cin >> age;
10    cout << "Halo " << name << endl;
11    cout << "Anda berumur " << age << " tahun!";

📖 Contoh Program Berguna & Mudah Diuji

Contoh 1

Menjumlahkan 2 Nombor

Menerima dua nombor bulat dan memaparkan hasil tambah.

int num1, num2;
cout << "First number: ";
cin >> num1;
cout << "Second number: ";
cin >> num2;
cout << "Total = " << num1 + num2;
💬 Ujian Debug: Jika input 5 & 8, output mestilah 13.
Contoh 2

Kira Luas Segi Empat

Menerima panjang & lebar (float) kemudian mengira luas.

float length, width;
cout << "Length: ";
cin >> length;
cout << "Width: ";
cin >> width;
cout << "Area = " << length * width;
💬 Ujian Debug: Jika panjang 4.5 & lebar 2.0, output mestilah 9.0.

Awas dengan Hama Pepijat (Ralat / Errors)!

Error bermaksud kesalahan dalam program yang menyebabkan sistem tidak boleh berjalan, mengeluarkan output yang salah, ataupun berhenti serta-merta semasa dijalankan. Mari kita kenali musuh utama pengaturcara ini!

❌
1

Syntax / Compile Error

Kesalahan penulisan kod yang melanggar peraturan tatabahasa C++. Kompiler (compiler) tidak faham apa yang cuba ditulis.

⚠️ Kod Salah:

cout << "Hello" (Tiada ;)

✅ Kod Betul:

cout << "Hello";
🚕 Analogi: Menulis ayat "Saya makan nasi" tanpa titik di hujung ayat. Pembaca faham tapi undang-undang bahasa rosak!
💥
2

Runtime Error

Program berjaya dikompil tetapi mengalami kegagalan kritikal di tengah-tengah jalan semasa program sedang dilaksanakan.

⚠️ Kod Salah:

int a = 10; int b = 0;
cout << a / b; (Bahagi dengan 0!)
🚗 Analogi: Enjin kereta boleh dihidupkan dengan jayanya, tetapi tayar kereta tiba-tiba meletup semasa anda sedang seronok memandu di jalan raya!
🔗
3

Linker Error

Berlaku apabila program cuba memanggil fungsi luar yang telah diisytiharkan, tetapi sistem penyambung (linker) tidak dapat mencari takrifan (definisi) fungsi tersebut.

⚠️ Contoh Situasi:

Anda isytihar fungsi void paparan(); di bahagian atas program, tetapi anda langsung tidak menulis kod isi kandungannya di mana-mana!

📦 Analogi: Anda menjumpai manual yang menyuruh anda mengambil "Alat A" dari kotak bungkusan, tetapi apabila dibuka, "Alat A" tiada dalam kotak!
🧠
4

Logic Error

Program berjalan dengan lancar tanpa sebarang mesej kerosakan, tetapi jawapan akhir yang dikeluarkan adalah salah sama sekali kerana formula yang digunakan tidak betul.

⚠️ Kod Salah Formula:

total = a - b; (Niat asal mahu tambah, tapi tertulis tolak!)

✅ Kod Betul Formula:

total = a + b;
🤔 Analogi: Anda ditanya 2 + 3 dan anda menjawab 6. Tiada ralat perkataan, tetapi logik pemikiran anda tersilap!
