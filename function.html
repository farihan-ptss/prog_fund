5.1.1 DEFINE FUNCTION Konsep Teras

Apakah itu Fungsi (Function)?

Fungsi ialah satu blok kod modular yang serba lengkap, dinamakan untuk melaksanakan tugas khusus, dan boleh diguna semula (reusable) berulang kali di mana-mana bahagian program.

Analogi Dunia Nyata: Pengisar Jus (Blender)

🍎🍊
Input (Argumen)
➔
⚙️ f(x)
Fungsi: buatJus()
➔
🧃
Output (Return)
Kata Kunci Utama: Modulariti, Berdikari (Self-contained), Input/Output, Pelaksanaan atas panggilan (Invoked on demand).
5.1.2 ADVANTAGES OF FUNCTION Kelebihan Menggunakan Fungsi

Mengapa Perlu Guna Fungsi?

♻️ Kebolehgunaan Semula

Tulis sekali, panggil berulang kali tanpa perlu menaip semula kod yang serupa (prinsip DRY: Don't Repeat Yourself).

🧩 Modulariti & Teratur

Memecahkan atur cara besar yang kompleks kepada unit-unit kecil yang mudah diurus (Divide and Conquer).

🐞 Nyahpepijat Mudah

Ralat (bug) dapat dikesan dan dibetulkan terus di dalam fungsi tertentu tanpa menjejaskan kod lain.

👥 Kerjasama Pasukan

Pengaturcara berbeza boleh membina modul fungsi berasingan serentak sebelum disatukan ke program utama.

⚡ Simulasi Visual: Program Tanpa Fungsi vs Dengan Fungsi

Bandingkan perbezaan kecekapan kod
❌ Tanpa Fungsi (Berulang & Padat) 18 Baris Kod 
// Kira Purata Murid 1
total1 = m1 + m2 + m3;
avg1 = total1 / 3.0;
cout << "Purata 1: " << avg1;

// Kira Purata Murid 2 (Kod berulang!)
total2 = m4 + m5 + m6;
avg2 = total2 / 3.0;
cout << "Purata 2: " << avg2;

// Kira Purata Murid 3 (Kod berulang lagi!)
total3 = m7 + m8 + m9;

cout << "Purata 3: " << avg3;
✅ Dengan Fungsi (Ringkas & Modular) Cuma Panggil 1 Fungsi 
// Takrif sekali sahaja
double kiraPurata(double a, double b, double c) {
    return (a + b + c) / 3.0;
}

// Guna berkali-kali!
cout << kiraPurata(m1, m2, m3);
cout << kiraPurata(m4, m5, m6);
cout << kiraPurata(m7, m8, m9);
5.1.3 TYPES OF FUNCTIONS

Dua Kategori Utama Fungsi

Dalam pengaturcaraan C/C++, fungsi terbahagi kepada fungsi sedia ada perpustakaan dan fungsi yang dicipta sendiri.

📚 a. Library / Built-in Functions

Pratafsir (Pre-defined)

Fungsi yang telah dibina siap dalam perpustakaan piawai bahasa pengaturcaraan. Pengaturcara hanya perlu memasukkan fail pengepala (#include <header>) sebelum menggunakannya.

Cuba Uji Fungsi Matematik (<cmath>) Live Demo
sqrt(16) = 4.00 (punca kuasa dua)
pow(16, 2) = 256.00 (kuasa)
Contoh header lain:
• <cmath>: sqrt(), pow(), abs(), sin()
• <cctype>: toupper(), tolower(), isdigit()

🛠️ b. User-defined Functions

Ciptaan Pengaturcara

Fungsi yang direka dan ditulis sendiri oleh pembangun atur cara mengikut keperluan spesifik sistem yang sedang dibangunkan.

Contoh C++: Kira Diskaun Pelanggan Kastam 
// Fungsi yang dicipta sendiri
double kiraDiskaun(double harga, double peratus) {
    double jimat = harga * (peratus / 100.0);
    return harga - jimat;
}

int main() {
    double hargaAkhir = kiraDiskaun(120.0, 15.0);
    cout << "Bayaran: RM" << hargaAkhir; // RM102.0
    return 0;
}
Ciri-ciri Utama:
Fleksibel mengikut logik sistem projek.
Mempunyai 3 komponen utama (Prototype, Definition, Call).
Aspek Perbandingan Library / Built-in User-Defined
Pencipta Pereka bahasa / Piawaian Kompiler (Standard Library). Pengaturcara / Pembangun projek sendiri.
Keperluan Fail Header Wajib disertakan (contoh: #include <cmath>). Tidak perlu header khas (hanya prototype jika takrifan di bawah main()).
Kebolehubahan (Modifiability) Kod teras dalaman tidak boleh diubah. Bebas diubah suai mengikut keperluan pada bila-bila masa.

5.2.3 Kod C++ Sebenar

Pass by Value

5.2.2 Rumusan Ringkas Perbezaan:

• Value: Menghantar salinan nilai sahaja. Nilai asal di main() kekal selamat.
• Reference: Menghantar alamat memori (simbol &). Nilai asal di main() ikut berubah.

📊 Jadual Perbandingan Terperinci (5.2.2)

Kriteria Penilaian Pass by Value Pass by Reference (&)
Perkara Yang Dihantar Salinan kandungan (copy of actual value). Alamat / Rujukan terus memori (memory address/alias).
Kesan Terhadap Pemboleh Ubah Asal TIDAK BERUBAH (Kekal asal). BERUBAH mengikut operasi fungsi.
Sintaks Parameter Header void swap(int a, int b) void swap(int &a, int &b)
Penggunaan Memori Memerlukan memori tambahan untuk simpanan salinan data. Lebih jimat memori kerana berkongsi lokasi memori asal sedia ada.
Contoh Kegunaan Terbaik Apabila data asal perlu dilindungi (cth: paparan, pengiraan sementara). Apabila fungsi perlu memulangkan lebih daripada 1 hasil (cth: pertukaran nilai/swap).
