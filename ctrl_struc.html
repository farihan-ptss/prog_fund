Modul 3.1

Apa Itu Struktur Kawalan Atur Cara? 🤔

Struktur kawalan ialah arahan yang menentukan **aliran pelaksanaan** kod dalam sesebuah program komputer. Tanpa struktur kawalan, komputer hanya menjalankan arahan dari atas ke bawah secara lurus!

3.1.1 Tiga Jenis Utama Struktur Kawalan

Setiap program komputer dibina menggunakan gabungan 3 struktur asas ini:

A. Turutan (Sequential)

Berurutan Langkah demi Langkah

Arahan dilaksanakan satu demi satu mengikut susunan berturut-turut dari atas ke bawah tanpa melompat atau mengulang.

1. Mula
2. Masukkan input A
3. Kira Jumlah = A + 10
4. Papar Jumlah
5. Tamat
B. Pilihan (Selection)

Membuat Keputusan

Memilih laluan atau blok kod tertentu untuk dilaksanakan berdasarkan **syarat (condition)** sama ada BENAR (True) atau PALSU (False).

JIKA markah >= 50:
  Papar "Lulus!"
JIKA TIDAK:
  Papar "Gagal"
C. Iterasi (Iteration)

Pengulangan (Repetition)

Mengulang blok arahan berulang kali berdasar syarat tertentu sehingga syarat penamatan dicapai.

ULANG (3 kali):
  Papar "Selamat Datang!"
TAMAT ULANG

Modul 3.2

3.2 Struktur Kawalan Pilihan (Selection)

Membolehkan program membuat keputusan mengikut penyataan `if` dan `switch case`.

if

a. Penyataan 'if'

Pilihan berdasarkan ungkapan Boolean (Benar/Palsu)

Menguji satu syarat. Jika syarat bernilai **TRUE**, blok kod di dalam penyataan akan dijalankan. Boleh berkembang kepada pelbagai variasi mengikut keperluan masalah.

switch

b. Penyataan 'switch case'

Pilihan berbilang nilai padanan khas

Digunakan apabila terdapat banyak pilihan nilai tetap (contoh: nombor hari 1-7 atau pilihan menu A/B/C). Membandingkan satu pembolehubah dengan pelbagai kes (case).

3.2.2 & 3.2.3 Sintaks & Atur Cara Jenis-jenis 'if'

Pilih jenis penyataan 'if' di bawah untuk melihat sintaks dan cuba simulasi programnya!

Sintaks Formatif Single if 
if (syarat) {
    // Kod dilaksanakan jika syarat TRUE
}
Penerangan: Pilihan tunggal. Kod hanya berjalan jika syarat dipenuhi.

Simulasi Penyelesaian Masalah

Uji Input

Masalah: Semak sama ada markah pengguna lulus (>= 50).

Hasil Output Terminal:
Tahniah! Anda LULUS dalam ujian.
3.2.4 & 3.2.5

Sintaks & Program 'switch case'

Menilai satu pembolehubah dan melompat ke label `case` yang sepadan.

Sintaks Switch Case C / C++ / Java / JS 
switch (ungkapan) {
    case nilai1:
        // Kod jika ungkapan == nilai1
        break;
    case nilai2:
        // Kod jika ungkapan == nilai2
        break;
    default:
        // Kod jika tiada kes yang padan
}

Contoh Masalah: Pilihan Menu Hari

Masukkan nombor hari (1 hingga 7) untuk menentukan menu hidangan istimewa kafeteria.

Hasil Output Switch Case:
Menu Isnin: Nasi Lemak Ayam Goreng 🍗
Modul 3.3

3.3 Struktur Kawalan Iterasi (Ulangan)

Mengulang blok kod menggunakan `while`, `do-while`, dan `for` secara sistematik.

while

a. while

Semak syarat DAHULU (Pre-test loop)

Syarat diuji terlebih dahulu sebelum blok kod dijalankan. Jika syarat dari awal bernilai Palsu, gelung tidak akan dijalankan walau sekali pun.

do..while

b. do while

Semak syarat KEMUDIAN (Post-test loop)

Kod dilaksanakan sekurang-kurangnya **SEKALI** sebelum syarat diuji di bahagian bawah.

for

c. for

Ulangan bilangan terpimpin / diketahui

Sesuai digunakan apabila bilangan pengulangan sudah diketahui dengan jelas sebelum gelung bermula.

3.3.2 Komponen Utama Penyataan Iterasi 🧩

Setiap gelung berulang yang betul MESTI mempunyai 3 komponen ini bagi mengelakkan **infinite loop** (gelung tanpa henti):

Komponen 1

a. Initialization (Permulaan)

Menetapkan nilai permulaan untuk pembolehubah pembilang (counter variable).
Contoh: `i = 1;`

Komponen 2

b. Termination (Penamatan)

Syarat Boolean yang mengawal sama ada gelung terus berulang atau berhenti.
Contoh: `i <= 5;`

Komponen 3

c. Increment / Decrement

Mengemas kini nilai pembilang pada setiap pusingan (tambah atau tolak).
Contoh: `i++` atau `i--`

3.3.3 & 3.3.4 Sintaks & Simulasi Interaktif

Simulasi Langkah-demi-Langkah Gelung (Loop Visualizer) 🔄

// Kod Gelung Terpilih:

}

3.3.5 & 3.3.6

Penyataan Melompat (Jump Statements)

Penyataan khas untuk mengendalikan atau mengubah aliran asal gelung secara tiba-tiba.

break

Hentikan Gelung Serta-merta

Keluar secara paksa daripada gelung sepenuhnya, dan meneruskan arahan selepas blok gelung.

continue

Langkau Pusingan Semasa

Melangkau baki kod dalam pusingan semasa dan terus melompat ke pusingan gelung seterusnya.

exit() / return

Tamatkan Keseluruhan Atur Cara

Menamatkan pelaksanaan keseluruhan program atau fungsi secara serta-merta.

Uji Program Penyataan Melompat (Jump Statement Demo)

Program asal mengira dari 1 hingga 5. Perhatikan bagaimana output berubah!

Hasil Output Jump Statement:
1 2 [BREAK TERCETUS! Gelung Diberhentikan]
